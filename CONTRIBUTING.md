## 🚀 How to Contribute

We welcome contributions in various forms, including but not limited to:

-   **Reporting Bugs:** If you find a bug, please create a detailed issue in the relevant repository.
-   **Suggesting Enhancements:** If you have an idea for a new feature or an improvement, please open an issue to discuss it.
-   **Pull Requests:** If you want to contribute code, please fork the repository and submit a pull request.

### Steps to Contribute

1.  **Fork the Repository:** Click the "Fork" button at the top right of the repository page.
2.  **Clone Your Fork:** `git clone https://github.com/your-username/repository-name.git`
3.  **Create a Branch:** `git checkout -b feature/your-feature-name`
4.  **Make Your Changes:** Write your code and add or modify tests.
5.  **Commit Your Changes:** `git commit -m "feat: Add your feature"`
6.  **Push to Your Fork:** `git push origin feature/your-feature-name`
7.  **Submit a Pull Request:** Open a pull request from your fork to the main repository.

## 📝 Code Style and Guidelines

To maintain code quality and consistency, we follow these guidelines:

-   **Code Formatting:** We use Prettier for code formatting. Please ensure your code is formatted before submitting a pull request.
-   **Linting:** We use ESLint for identifying and fixing problems in our code.
-   **Testing:** We use Jest for testing. Please add tests for your code and ensure all tests pass.
